# WindowCleaner — Repo Guide

WindowCleaner is a native **macOS menu bar app** that closes stale windows of other apps. The user sets per-app rules ("close Finder windows 6 hours after I last used them"), and WindowCleaner closes each window when its time is up. It works per **window**, not per process. Private, local, macOS 15+.

**Current stage:** Phase 1 (Scaffolding) is built. The repo has `WindowCleanerKit` (all modules as stubs), the thin `App/` shell (XcodeGen, menu bar app), the `ManualTestApp/` (hardware test harness), `ManualTestKit` + `manual-tests-check`, Makefile, lint/format, CI, hooks-mcp, and pre-commit hook. `make ci` is green.

## Conventions and gotchas

- **macOS 15+ only.** Swift 6, strict concurrency, warnings-as-errors.
- **Swift-package-first.** All logic lives in `Packages/WindowCleanerKit` and builds/tests with `swift build` / `swift test`. The app target is only the composition root.
- **No third-party dependencies.** The package has zero external dependencies.
- **Bundle ID is locked:** `net.scosman.windowcleaner`. Do not change it (TCC grants persist against it).
- **Signing/TCC:** Accessibility grants are bound to the code signature. Ad-hoc builds lose the grant on every rebuild. Local runs use the team's Apple Development identity (`make run-app`, `make run-manual-tests`). Reset a grant with `tccutil reset Accessibility net.scosman.windowcleaner`.
- **Observation in scenes:** Scene closures do not track `@Observable` reliably. The Biscotti workaround: a wrapper View stores the state, and the scene closure reads it.
- **Tests use Swift Testing** (`import Testing`), not XCTest.
- **`os.Logger`** with subsystem `net.scosman.windowcleaner` and a per-component category. Never `print`. Window titles use `privacy: .private`.
- **`// TODO:` markers** track deferred pre-ship work. SwiftLint's `todo` rule is disabled.

### Sandbox gotcha

`swift build`, `swift test`, and `xcodebuild` **fail under the agent Bash sandbox** (llbuild EPERM). Agents use the `hooks-mcp` MCP tools for anything that compiles. Only `make lint`/`format` are safe in Bash once `.tools/` is populated.

## Build and checks

### Makefile (the canonical command surface)

| Target | Does | Gating? |
|---|---|---|
| `make bootstrap` | Install dev tools via Homebrew + fetch pinned SwiftLint/SwiftFormat | --- |
| `make generate` | Generate `.xcodeproj` from `project.yml` (XcodeGen) | --- |
| `make build` | `swift build` the SPM package | --- |
| `make test` | `swift test` (filtered output) | Yes |
| `make lint` | `swiftformat --lint` + `swiftlint --strict` | Yes |
| `make format` | Auto-format (SwiftFormat then SwiftLint `--fix`) | --- |
| `make precommit-checks` | `format` + `lint` + `test` | Yes |
| `make build-app` | `generate` + `xcodebuild` both apps (ad-hoc) | Non-gating |
| `make run-app` | Debug build + run the app (Apple Development signing) | --- |
| `make run-manual-tests` | Debug build + run ManualTestApp | --- |
| `make hooks` | Point git at `.githooks/pre-commit` | --- |
| `make ci` | `lint` + `test` + `build` | --- |
| `make manual-tests-check` | Check all manual test steps have been run | Non-gating |
| `make clean` | Remove `.build/`, generated projects, DerivedData | --- |

### CI (three tiers)

CI pins **Xcode 26.3** via `DEVELOPER_DIR` (the `macos-15` runner's default Xcode has SwiftData `Sendable` issues under Swift 6).

- **`package-tier`** (gating, required check): `make ci`.
- **`app-tier`** (non-gating, `continue-on-error`): `make build-app`.
- **`manual-tests-check`** (non-gating, `continue-on-error`): `make manual-tests-check`.

### Agent command surface (hooks-mcp)

Agents use `hooks-mcp` MCP tools: `mcp__hooks-mcp__build`, `…__test`, `…__lint`, `…__format`, `…__precommit_checks`, `…__build_app`, `…__generate`, `…__bootstrap`, `…__manual_tests_check`. These run outside the Bash sandbox.

**XcodeBuildMCP** is also registered in `.mcp.json`.

## Pre-commit and the Claude Code agent

The `.githooks/pre-commit` hook runs `make precommit-checks` (format + lint + test). It cannot run inside the agent sandbox (Swift toolchain EPERM). The hook detects `$CLAUDECODE` and fails fast with instructions.

**Agent commit protocol:**

1. Run `mcp__hooks-mcp__precommit_checks`.
2. Only if it passes green, and with **no code changes** since that run, commit with `--no-verify`.

---

## Manual test staleness rule

Any change to `Packages/WindowCleanerKit/Sources/SystemBridge` sets all `sb_*` steps to `not-run`. The `manual-tests-check` gate is red until every recordable step has a result.
